# Neon OS · Lore notes

Decisions for the game. Neon OS itself stays a clean, usable tool; none of this appears in the apps.

**On hold (12 Oct 2026):** the game waits until Neon OS is a complete, installable OS. These notes stay for when it starts.

## Settled (12 Oct 2026)

| Question | Decision |
| --- | --- |
| What the orb is | **A sleeping mind.** A consciousness aboard the ship, dreaming. It drifts in the half-awake state (微睡み, madoromi), which is why it moves with the music. |
| Tone | **Chill but chaotic**, the same as MadoromiTV: calm and dreamy by default, with short bursts of static and mischief when something wakes it. |
| The player | **The last crew member**, alone aboard, keeping the ship running with these systems. |
| Lore in Neon OS | **None.** It's saved for the game. |
| What the game is | **A standalone game, operated through and styled like Neon OS, that runs on its own.** It doesn't need Neon OS installed; the player works the ship through Neon OS-style windows and apps inside the game. |

## Threads to explore
