CYAN
Orb colour

Every Neon OS app and window follows this colour straight away.

Desktop
Icons on the desktop

Drag icons on the desktop to move them; right-click the desktop and pick Arrange icons to put them back in order.

Accessibility

High contrast makes text brighter and edges and keyboard focus easier to see. Reduce motion stops the wallpaper moving and turns off slides and fades (it starts on if your system asks for less motion). Press ? anywhere for every keyboard shortcut.

Storage and install
CHECKING STORAGE…

Browsers can clear stored songs when a computer runs low on space. A protected library is only cleared if you clear it yourself.

Backup
CHECKING LIBRARY…

One file with your songs, playlists, notes and settings. Keep it somewhere safe, or restore it in another browser or on another computer.

System

Reset puts every window back to its default size the next time Neon OS opens. Boot screen turns the start-up sequence on or off.
